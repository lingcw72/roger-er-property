# Approved Copy Source

Keep readable, approved source copy here before updating public HTML in `website-files/`. Suggested files include `faq.md`, `home.md`, `about.md`, `services.md`, `articles/` and `projects/`.

For every source file, record the approver and date. When a source changes, update the related public HTML page, internal links, metadata and sitemap where applicable. Do not store credentials or unapproved claims here.
