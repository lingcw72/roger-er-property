# Roger Er personal property website

A static, bilingual website built with HTML, CSS and vanilla JavaScript for GitHub Pages.

The preview is currently marked `noindex, nofollow`, and `robots.txt` disallows
all compliant crawlers. Remove both protections when the final site is ready
for search engines.

## Preview locally

Run:

```sh
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Before launch

1. Replace the placeholder phone number and email in `index.html`.
2. Replace the provisional AI portrait with Roger's approved professional photograph.
3. Confirm all transaction figures and update the “checked” date when refreshing the site.

## Image note

`assets/roger-er-portrait-concept.png` is an AI-generated portrait concept created from Roger's public profile photograph. It is intended as a temporary art-direction reference, not as documentary photography.
