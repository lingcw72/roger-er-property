## Implementation and validation

1. Complete the cookie policy, privacy policy and integration inventory before launch.
2. Configure consent defaults before analytics/advertising tags can fire.
3. Test accept, reject and change-preference paths.
4. Confirm essential site functions still work when non-essential choices are rejected.
5. Record the configuration and validation result in the technical register and change log.
