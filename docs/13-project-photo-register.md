## Photo workflow

1. Store originals outside `website-files/`; retain the source and approval record.
2. Select only accurate, representative images and avoid misleading before/after editing.
3. Prepare correctly sized WebP/AVIF or other approved web formats; keep an appropriate fallback where required.
4. Add meaningful alt text and a caption only when it provides useful context.
5. Add the approved project/gallery card, related page links, metadata and sitemap entry together.
